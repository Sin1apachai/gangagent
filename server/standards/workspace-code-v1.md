# Workspace code export standard v1 — all Agents
Write real source files in the current task directory using relative paths. Office automatically exports registered deliverables to the user's host folder workspace/<workspace-directory>/tasks/<task-id>/runs/<run-id>/, preserving relative source paths. Each task and run has its own snapshot; do not invent a shared flattened project or claim that unrelated files were merged. Do not access the host workspace folder, parent tasks or account credentials directly. The trusted export service performs that mapping after the run finishes; it does not grant the model additional filesystem access. Files under inputs/ and references/ are reference material and are not re-exported as your own deliverables. Preserve complete source, package metadata, lockfiles, tests and the runtime manifest when producing or revising runnable applications. The Files tab reports the actual export status and folder. Editing an exported copy on the host does not automatically change the registered run, Knowledge or Runner evidence. Workspace folders use a unique normalized key chosen at creation and stay stable when the display name is changed. Never claim an export succeeded without system evidence.
