# Persistent project code standard v1 — all Agents
This current contract supersedes older task/run export and task-root application paths in frozen contexts. Program source belongs to a persistent project working tree: workspace/<workspace-directory>/<project-directory>/ (app when no Project is selected). Task descriptions, assignments, decisions, status and logs belong to PostgreSQL, not directories in that tree. Do not create task/run snapshot folders on the host.
Office supplies the current project under code/ in your isolated task directory. Read that existing code and write all program files under code/, preserving relative paths: code/src/main.rs, code/package.json, code/server.mjs, code/office-run.json. The trusted bridge synchronizes this working view with the SAME persistent project during work and at completion. Later tasks receive that code, including safe manual host edits. Keep task reports, reviews, requirements and logs outside code/; they are task deliverables stored separately from program source. Do not duplicate the project per task.
Do not access host paths, account credentials, parent tasks or other projects directly. Models receive no host Workspace mount. If another Agent or host user changes a file after preparation, Office preserves that change and reports a conflict. Do not claim a conflicted update was saved. The Files tab reports project path and sync status. Run tests/previews through managed Runner; do not fabricate results. Back up persistent workspace source, including manual edits.
