# Design assets

Pixel sprite sheets and the embedded Pixelify font were extracted from the designer export supplied for Agent Office. No prototype records are seeded into the app. The font uses the SIL Open Font License.

The curated screenshots in `docs/images/` were captured from the running application and approved for inclusion in the usage guide. Raw screenshots remain in the ignored local `docs/screenshots/` directory. No provider authorization codes, tokens, passwords or private credential files are included.
